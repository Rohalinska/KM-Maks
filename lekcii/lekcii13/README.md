## Контрольні запитання

1. **Задачі мережі:** Передавати файли, друкувати на спільному принтері, відкривати сайти та спілкуватися між комп'ютерами.
2. **Надійність «Зірки» та «Кільця»:**
* **Зірка:** Зламається один ПК - інші працюють. Зламається центральний роутер/світч - мережа повністю впаде.
* **Кільце:** Зламається хоч один ПК або кабель - зупиниться вся мережа.


3. **Різниця між комутаціями:**
* **Комутація каналів:** Лінія повністю займається двома пристроями на весь час розмови (як старий телефон).
* **Комутація пакетів:** Дані діляться на шматочки (пакети) і йдуть спільною мережею разом з іншими (як інтернет).


4. **OSI та TCP/IP:**
* **OSI** має **7 рівнів**, а **TCP/IP** - **4 рівні**. TCP/IP просто об'єднує кілька сусідніх рівнів OSI у більші блоки.

5. **Інкапсуляція:** Це як запаковування листа в конверти: до даних послідовно додаються порти, потім IP-адреси, а в кінці - MAC-адреси для відправки по кабелю.
6. **IEEE та IETF:**
* **IEEE** робить стандарти для «заліза» та дротів/радіохвиль (Ethernet, Wi-Fi).
* **IETF** створює правила та протоколи для інтернету (IP, HTTP, DNS).


7. **Кабелі для 8 комп'ютерів:**
* **Комірчаста (Mesh):** потрібно **28 кабелів** (кожен комп'ютер з'єднується з кожним).
* **Зірка:** потрібно всього **8 кабелів** (кожен ПК йде до центрального світча).


8. **Статуси RFC:**
* **Proposed Standard:** новий стандарт, який ще перевіряють.
* **Internet Standard:** повністю прийнятий та офіційний стандарт Інтернету.
* **Obsoleted by:** вказує номер новішого документа, який замінив цей застарілий.


9. **IEEE 802.11 vs 802.3:**
* **802.11:** це стандарт **Wi-Fi** (бездротовий).
* **802.3:** це стандарт **Ethernet** (дротовий).

## Домашнє завдання

### 1. Порівняння топологій

| Критерій | Топологія «Зірка» | Топологія «Кільце» |
| --- | --- | --- |
| **Кількість кабелів для $N$ комп'ютерів** | $N$ | $N$ |
| **Якщо зламався один ПК** | Все працює далі | Вся мережа лягає |
| **Якщо зламався центр (для Зірки) / кабель (для Кільця)** | Вся мережа лягає | Вся мережа лягає |

### 2. Перевірка через F12 у браузері

1. Відкрийте будь-який сайт $\rightarrow$ натисніть **F12** $\rightarrow$ перейдіть у вкладку **Network** $\rightarrow$ оновіть сторінку (F5).
2. Натисніть на найперший рядок у списку та гляньте вкладку **Headers**:
* **Порт:** `443` (якщо сайт захищений HTTPS) або `80` (якщо HTTP).
* **Версія:** `h2` (HTTP/2) або `HTTP/1.1`.

### 3. Різниця комутацій (коротко)

Комутація каналів виділяє окрему лінію тільки під двох абонентів на увесь час розмови (як телефонний дзвінок). Комутація пакетів розбиває дані на шматочки та передає їх разом із даними інших користувачів через спільні лінії (як інтернет).
