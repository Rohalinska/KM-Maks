## Контрольні запитання

### 1. Відмінність асемблера

* **Від мов високого рівня:** низькорівневий, кожній інструкції відповідає одна команда процесора (1:1), робота йде напряму з регістрами та RAM без системних абстракцій.
* **Від машинного коду:** використовує текстові мнемоніки (`add`, `lw`), а не бінарний чи 16-ричний код (`0x005B0533`).

### 2. Особливість `x0` у RISC-V

Регістр `x0` (`zero`) апаратно зафіксований на значення **0**. Запис у нього ігнорується, а читання завжди повертає `0`. Використовується для спрощення команд (наприклад, `nop` чи очищення регістрів).

### 3. Регістри ABI (аргументи та повернення)

* **Передача аргументів:** `a0`-`a7` (`x10`-`x17`).
* **Повернене значення:** `a0`, `a1` (`x10`, `x11`).

### 4. `.data` vs `.text`

* **`.data`:** секція для оголошення статичних змінних, масивів і рядків.
* **`.text`:** секція для машинного коду (інструкцій).

### 5. Виклик підпрограми в RISC-V

1. Запис аргументів у `a0`-`a7`.
2. Перехід `jal ra, Label` (збереження адреси повернення в `ra`).
3. Пролог: збереження `ra` та `s`-регістрів у стек (за потреби).
4. Виконання коду.
5. Епілог: відновлення збережених регістрів.
6. Повернення через `ret` (`jalr x0, 0(ra)`).

### 6. Доступ до пам’яті (RISC-V vs x86)

* **RISC-V:** вимагає спочатку зчитати дані в регістр (`lw`), і лише потім додавати (`add`).
* **x86:** дозволяє додавати значення безпосередньо з пам'яті (`add eax, [ebx]`).

### 7. `s`-регістри (callee-saved)

Викликана підпрограма зобов'язана зберегти їх у стек і відновити перед виходом. Якщо цього не зробити, викликаюча програма втратить свої власні дані в цих регістрах.

### 8. Номери сервісів `ecall` у RARS (`a7`)

* **Друк числа:** `1`
* **Друк рядка:** `4`
* **Завершення програми:** `10`

### 9. Масштабування індексу `int`

`int` займає 4 байти, тому зміщення дорівнює $\text{індекс} \times 4$. Ефективно виконується зсувом вліво на 2 біти: **`slli rd, rs, 2`**.

## Домашнє завдання

### 1. Підпрограма `cube(x)`

```assembly
cube:
    mul t0, a0, a0    # t0 = x^2
    mul a0, t0, a0    # a0 = x^3
    ret

```

### 2. Трасування регістрів (`a0`, `ra`)

* **До виклику (`li a0, 6`):** `a0 = 6`, `ra = system_addr`
* **Під час `jal ra, square`:** `a0 = 6`, `ra = main_return_addr`
* **Усередині `square` (`mul`):** `a0 = 36`, `ra = main_return_addr`
* **Після `ret`:** `a0 = 36`, `ra = main_return_addr`

### 3. Рядок доступу до пам'яті

* **RISC-V:** `lw t0, 0(x6)` - окремо завантажує дані з RAM у регістр.
* **x86:** `add eax, [ebx]` - читає з RAM і додає до `eax` за одну інструкцію.
