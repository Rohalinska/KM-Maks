## Контрольні запитання

1. **Роутер vs Світч:** Світч з'єднує ПК в одній мережі за MAC. Роутер з'єднує різні мережі за IP.
2. **Найдовший збіг префікса:** Правило вибору найточнішого маршруту з найбільшою маскою ($/X$).
3. **RIP vs OSPF:** RIP рахує хопи (повільний). OSPF рахує швидкість каналів (швидкий).
4. **Роль BGP:** З'єднує мережі провайдерів та країн у єдиний глобальний інтернет.
5. **Види NAT:**
* *Статичний:* 1 внутрішній IP = 1 постійний зовнішній IP.
* *Динамічний:* 1 внутрішній IP = 1 тимчасовий зовнішній IP з пулу.
* *PAT:* багато внутрішніх IP = 1 зовнішній IP (різні порти).

6. **Проброс портів:** Вказує роутеру за NAT, на який саме внутрішній ПК переправляти вхідний запит.
7. **Обрив каналу:** Статичний маршрут глухий і шле дані в нікуди. Динамічний - миттєво знаходить обхід.
8. **Вибір шляху RIP/OSPF:** RIP обрав коротший шлях за роутерами, OSPF - за швидкістю. Шлях OSPF вигідніший, бо він швидший.
9. **Поля `show ip nat translations`:**
* *Inside local:* локальний IP пристрою.
* *Inside global:* зовнішній IP роутера для цього пристрою.
* *Outside local/global:* IP зовнішнього сервера.
